## 2) 체크포인트 실행 체크리스트

### T+0h (배포 직후 ~ 30분)
- [ ] 배포 완료 여부 및 아티팩트 버전(`0.4.0`) 일치 확인
- [ ] 테스트 게이트 결과 수집 및 통과율 산출
- [ ] Smoke 테스트 실행 결과 수집 및 실패율 산출
- [ ] 초기 이슈(버그/장애/문의) 발생 건수 기록
- [ ] 알람/트리거 3종(`async 검색 실패`, `선택 이벤트 계약 회귀`, `import 실패`) 모니터링 시작
- [ ] 워룸 채널에 "T+0h 점검 완료" 공유

### T+4h
- [ ] 지난 4시간 핵심 지표 추이(증가/감소/급등) 확인
- [ ] Smoke 실패 재현 여부 및 일시 장애 여부 확인
- [ ] 알람/트리거 발생 내역 검토 및 미해결 건 에스컬레이션
- [ ] 신규 이슈 우선순위(Sev1/Sev2/Sev3) 재분류
- [ ] 워룸 채널에 "T+4h 점검 완료" 공유

### T+24h
- [ ] 24시간 누적 테스트 게이트 통과율 재계산
- [ ] 24시간 누적 Smoke 실패율 재계산
- [ ] 24시간 누적 이슈 발생 건수 집계(중대/일반 분리)
- [ ] 반복 발생 패턴(동일 원인/동일 구간) 확인
- [ ] 롤백 필요성 재평가(트리거 조건 충족 여부 기반)
- [ ] 워룸 채널에 "T+24h 점검 완료" 공유

### T+48h (종료 점검)
- [ ] 48시간 누적 지표 최종 기록
- [ ] 미해결 이슈 잔여 목록 및 후속 담당자 지정
- [ ] 중대 이슈(Sev1/Sev2) 0건 유지 여부 최종 확인
- [ ] 종료 기준 충족 여부 확인 후 모니터링 종료 결정
- [ ] 워룸 채널에 "T+48h 종료 보고" 공유

## 4) 알람/트리거 및 즉시 조치
| 트리거 | 탐지 신호 예시 | 발생 판단 기준 | 즉시 조치 | 에스컬레이션 |
|---|---|---|---|---|
| async 검색 실패 | 비동기 검색 API 오류율 증가, 타임아웃 급증 | 5분 이동 구간 실패율 임계치 초과 또는 연속 실패 감지 | 해당 기능 트래픽/큐 상태 점검, 최근 배포 변경점 확인, 장애 티켓 생성 | On-call 엔지니어 → 릴리스 책임자 → 제품/운영 공지 |
| 선택 이벤트 계약 회귀 | 이벤트 필드 누락/타입 불일치, 컨슈머 파싱 실패 | 계약 검증 실패 1건 이상 또는 주요 이벤트 소비 실패 발생 | 계약 스키마 즉시 검증, 회귀 커밋 후보 식별, hotfix 또는 롤백 결정 | On-call 엔지니어 → FE/BE 오너 동시 호출 |
| import 실패 | import 작업 실패율 급증, 재시도 반복 실패 | 5분 구간 실패율 임계치 초과 또는 핵심 고객 플로우 차단 | 작업 중지/재시도 정책 확인, 입력 데이터/스토리지 상태 점검, 장애 공지 초안 작성 | On-call 엔지니어 → 데이터/플랫폼 담당자 → 릴리스 책임자 |

실행 체크:
- [ ] 트리거 발생 시각/증상/영향 범위 기록
- [ ] 15분 내 1차 원인 가설 및 임시 완화 조치 기록
- [ ] 30분 내 롤백 여부 의사결정

## 5) 장애 발생 시 롤백 절차

### 5-1. 롤백 실행 체크리스트
1. [ ] 장애 선언: 중대 영향(Sev1/Sev2) 여부 및 사용자 영향 범위 확정
2. [ ] 변경 동결: 추가 배포/마이그레이션/설정 변경 즉시 중단
3. [ ] 롤백 대상 확정: 직전 안정 릴리스 버전/태그 확인
4. [ ] 롤백 실행: 배포 파이프라인에서 이전 안정 버전으로 즉시 전환
5. [ ] 검증 수행: 핵심 경로 Smoke 테스트 및 트리거 3종 재확인
6. [ ] 상태 전파: 워룸/이해관계자에게 롤백 시작·완료·검증 결과 공지
7. [ ] 사후 기록: 장애 타임라인, 원인, 후속 액션(재발 방지) 등록
