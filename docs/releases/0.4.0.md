# 0.4.0 릴리스 노트 (초안)

## 메타
- 버전: `0.4.0`
- 상태: `General Availability`
- 작성일: `2026-03-04`
- 릴리스 성격: `비파괴 개선(Non-breaking)`

## 1) 릴리스 목적/범위
- `0.4.0`은 `0.4.0-rc.1` 검증 결과를 반영해 안정화된 개선사항을 정식 릴리스로 제공한다.
- 본 릴리스의 범위는 공개 계약 파괴 없이 다음 영역의 신뢰성과 운영 일관성을 높이는 데 있다.
  - async 인덱스 안정성
  - 로딩 상태 기반 no-result 노출 정책
  - warning 가드와 로그 폭주 방지
  - 공개 보조 API(export) 확장

## 2) 주요 변경점
1. async 인덱스 안정화
- RegionDataSource의 sync/async/혼합 반환 시나리오에서 인덱스 생성/조회 동작을 일관화했다.
- 인덱스 상태 기반 처리로 비동기 준비 구간에서의 불안정한 UI 전이를 완화했다.

2. no-result loading 정책
- 인덱스가 `loading`일 때 no-result를 노출하지 않는다.
- 인덱스 `ready` + 결과 0건 조건에서만 no-result를 노출한다.

3. warning 가드
- 개발 환경 전용 warning 가드 및 warning-once 정책을 적용해 중복 경고를 제한했다.
- `selectors` 누락/빈 배열, plugin type 미매칭, duplicate selector type(first-wins), deprecated 입력 안내를 표준 경고 경로로 통합했다.

4. 공개 export 3종
- 아래 3개 API를 공식 공개 export로 제공한다.
  - `createSelectorResolutionWarningContext`
  - `resolveSelectorsWithPolicy`
  - `validateSelectorTypeUniqueness`

## 3) 검증 결과 요약
- 정식 릴리스 게이트 결과: `lint/test/build:lib/verify:package 통과`.
- 패키지 소비자 관점 검증(`verify:package`)을 포함해 배포 가능 상태를 확인했다.

## 4) 롤백 기준/절차 요약
- 롤백 기준(요약):
  - async 검색 실패율 급증 또는 연속 실패
  - 선택 이벤트 계약 회귀 감지
  - import 실패로 인한 핵심 사용자 플로우 차단
- 롤백 절차(요약):
  1. 장애 선언 및 변경 동결
  2. 직전 안정 버전으로 즉시 전환
  3. Smoke/핵심 지표 재검증
  4. 상태 공지 및 사후 원인 기록
- 상세 운영 문서: [0.4.0 배포 후 48시간 사후 점검 런북](./0.4.0-post-release-monitoring.md)

## 5) 소비자 영향 및 마이그레이션 가이드
- 소비자 영향: `0.3.x` V2 계약 사용자에게 추가 코드 마이그레이션은 필수 아님.
- 권장 확인 사항:
  - no-result 노출 조건(`loading` 미노출, `ready+0건` 노출) 기반의 UI/테스트 기대값 점검
  - warning-once 정책 반영 후 개발 로그 집계 기준 점검
- 마이그레이션 가이드:
  - [0.3.0 마이그레이션 노트](../migration-notes/0.3.0-migration.md)
  - [ComposableSearch API 사용 가이드](../api-usage-guide.md)
