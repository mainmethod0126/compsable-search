# 0.4.0-rc.1 릴리스 노트 (초안)

## 메타
- 버전: `0.4.0-rc.1`
- 상태: `Release Candidate`
- 작성일: `2026-03-04`
- 릴리스 성격: `비파괴 개선(Non-breaking)`

## 1) 릴리스 목적/범위
- `0.4.0-rc.1`은 `0.3.x` 소비자 계약을 유지한 상태에서, 지역 검색/경고/공개 API 사용성을 안정화하기 위한 RC 릴리스다.
- 범위는 런타임 파괴 변경 없이 다음 품질 축에 집중한다.
  - async 인덱스 동작 안정성
  - 로딩 중 no-result 노출 정책 일관성
  - 개발 경고(warning) 가드 정합성
  - 공개 export 보강으로 소비자 진단/정책 제어성 강화

## 2) 주요 변경점
1. async 인덱스 안정화
- RegionDataSource의 sync/async/혼합 구현에서 상단 지역 검색 인덱스 빌드/조회 흐름을 동일 계약으로 정리했다.
- 인덱스 준비 상태 전이(`loading -> ready`)를 기준으로 UI 노출 타이밍을 일관화했다.

2. no-result loading 정책 고정
- 인덱스가 `loading`인 동안 `searchNoResultMessage`를 노출하지 않는다.
- 인덱스가 `ready`이고 검색 결과가 0건일 때만 no-result를 노출한다.

3. warning 가드 강화
- 개발 환경에서만 warning을 출력하고, 동일 이슈는 warning-once 정책으로 제한한다.
- 주요 가드 대상:
  - `selectors` 누락/빈 배열
  - runtime plugin `type` 미매칭
  - duplicate selector type(first-wins)
  - deprecated 입력(`selectorsProps`, `onChange`) 런타임 미지원 안내

4. 공개 export 3종 추가
- 루트 엔트리에서 아래 보조 API를 정식 공개한다.
  - `createSelectorResolutionWarningContext`
  - `resolveSelectorsWithPolicy`
  - `validateSelectorTypeUniqueness`

## 3) 검증 결과 요약
- 릴리스 게이트 기준 검증 결과: `lint/test/build:lib/verify:package 통과`.
- 소비자 패키징 검증은 `verify:package` 결과를 기준으로 합격 처리했다.

## 4) 롤백 기준/절차 요약
- 롤백 기준(요약):
  - async 검색 실패가 임계치를 초과하거나 연속 실패가 발생
  - 선택 이벤트 계약 회귀(필수 필드 누락/타입 불일치) 1건 이상 확인
  - import 실패가 임계치를 초과하여 핵심 플로우가 차단
- 롤백 절차(요약):
  1. 장애 선언 및 변경 동결
  2. 직전 안정 버전 확인 및 롤백 실행
  3. Smoke/핵심 지표 재검증
  4. 워룸 공지 및 사후 기록 등록
- 상세 운영 절차: [0.4.0 배포 후 48시간 사후 점검 런북](./0.4.0-post-release-monitoring.md)

## 5) 소비자 영향 및 마이그레이션 가이드
- 소비자 영향: `0.3.x` 기준 API 파괴 변경은 없으며, 기존 V2 사용 코드는 그대로 유지 가능하다.
- 권장 점검:
  - 로딩 중 no-result 미노출 정책에 의존하는 UI 테스트를 업데이트/확인
  - warning-once 기반 로그 수집 정책 적용 여부 확인
- 마이그레이션 가이드:
  - [0.3.0 마이그레이션 노트](../migration-notes/0.3.0-migration.md)
  - [ComposableSearch API 사용 가이드](../api-usage-guide.md)
