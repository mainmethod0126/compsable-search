# 0.3.0 마이그레이션 노트 (V2 Generic Selector 기준)

## 메타

- 대상 버전: `legacy 0.x -> V2 0.3.0`
- 문서 버전: `v2-breaking`
- 마지막 갱신: `2026-03-04`

## 1. V2 기준 변경 요약

V2는 0.x 라인의 breaking 전환이며, 아래 계약을 기준으로 마이그레이션해야 합니다.

- selector 입력 경로는 `selectors`만 사용한다.
- 상태 변경 이벤트는 `onValueChange(nextValue, meta)`만 사용한다.
- `meta.source`는 `selector | external`만 사용한다.
- `region | keyword` 구분은 `meta.selectorType`으로 처리한다.
- placeholder 키는 `placeholder`를 사용한다.
- Region 데이터소스는 sync/async(`MaybePromise`)와 optional `context.signal` 계약을 따른다.
- 상단 지역 검색 인덱스는 RegionDataSource가 sync/async 또는 혼합 구현이어도 동일하게 동작한다.
- 지역 검색 인덱스가 `loading` 상태인 동안에는 no-result를 노출하지 않고, `ready` + 결과 0건에서만 no-result를 노출한다.
- 개발 경고는 warning-once 정책을 따른다(`selectors` 누락/빈 배열, plugin-selector type 미매칭, duplicate selector type first-wins).

## 2. V2 기준 계약 ↔ 레거시 매핑

| V2 기준 계약 | 레거시/이전 패턴 | 마이그레이션 액션 | 비고 |
| --- | --- | --- | --- |
| `selectors={[...]}` | `selectorsProps={[...]}` (deprecated) | selector 입력을 `selectors`로 통일 | deprecated 항목은 타입 호환만 제공, 런타임 미지원 |
| `onValueChange={(nextValue, meta) => ...}` | `onChange={(items) => ...}` (deprecated) | 핸들러를 `onValueChange` 시그니처로 교체 | deprecated 항목은 타입 호환만 제공, 런타임 미지원 |
| `placeholder` | `placeHolder` (deprecated) | 옵션 키를 `placeholder`로 치환 | deprecated 항목은 타입 호환만 제공, 런타임 미지원 |
| `meta.source === 'selector' \| 'external'` | `meta.source === 'region' \| 'keyword'` (deprecated) | source 해석은 `selector | external`로 고정하고 selector 종류는 `meta.selectorType` 사용 | legacy source 값은 타입 호환만 유지, 런타임에서 내려오지 않음 |

## 3. 체크리스트

- [ ] `selectorsProps` 전달을 제거하고 `selectors`로 전환했다.
- [ ] `onChange`를 `onValueChange`로 전환했다.
- [ ] `placeHolder`를 `placeholder`로 치환했다.
- [ ] 로깅/분석 코드가 `meta.source`를 `selector | external` 기준으로 처리하고 `meta.selectorType`을 분리 사용한다.
- [ ] deprecated 별칭/값을 런타임 입력에서 제거했다.
- [ ] Region 데이터소스가 sync/async/혼합 구현 모두에서 상단 지역 검색 인덱스 계약을 만족하는지 검증했다.
- [ ] 지역 검색 인덱스 `loading` 중에는 no-result가 노출되지 않고, `ready` + 결과 0건에서만 노출되는지 검증했다.
- [ ] 개발 경고 정책(`selectors` 누락/빈 배열, plugin-selector type 미매칭, duplicate selector type first-wins + warning-once)을 검증했다.

## 4. After / Before

### After (V2 Generic Selector)

```tsx
import {
  ComposableSearch,
  createSelector,
  type ComposableSearchProps,
  type SelectionItem,
  type SelectorDriver,
} from 'compsable-search'

interface DemoSelectorProps {
  options?: { placeholder?: string }
  items: Array<{ id: string; label: string }>
}

const regionDriver: SelectorDriver<DemoSelectorProps, 'region', SelectionItem> = {
  type: 'region',
  getTriggerLabel: (props) => props.options?.placeholder ?? '지역 선택',
  loadItems: async (_context, props) =>
    props.items.map((item) => ({
      id: item.id,
      displayName: item.label,
      selectorId: 'region-main',
      selectorType: 'region',
    })),
  renderPanel: () => null,
}

const keywordDriver: SelectorDriver<DemoSelectorProps, 'keyword', SelectionItem> = {
  type: 'keyword',
  getTriggerLabel: (props) => props.options?.placeholder ?? '키워드 선택',
  loadItems: (_context, props) =>
    props.items.map((item) => ({
      id: item.id,
      displayName: item.label,
      selectorId: 'keyword-main',
      selectorType: 'keyword',
    })),
  renderPanel: () => null,
}

const selectors = [
  createSelector({
    id: 'region-main',
    type: 'region',
    props: {
      options: { placeholder: '지역 선택' },
      items: [{ id: '11', label: '서울특별시' }],
    },
    driver: regionDriver,
  }),
  createSelector({
    id: 'keyword-main',
    type: 'keyword',
    props: {
      options: { placeholder: '키워드 선택' },
      items: [{ id: 'kw:원룸', label: '원룸' }],
    },
    driver: keywordDriver,
  }),
] satisfies NonNullable<ComposableSearchProps['selectors']>

<ComposableSearch
  defaultValue={[]}
  selectors={selectors}
  onValueChange={(nextValue, meta) => {
    console.log(meta.reason ?? 'replace', meta.source, meta.selectorType)
    console.log(nextValue)
  }}
/>
```

## 5. Deprecated 호환 메모

- `selectorsProps`, `onChange`, `placeHolder`, `meta.source`의 legacy 값(`region`, `keyword`)은 점진적 전환을 위한 타입 호환 레이어로만 취급한다.
- 위 항목들은 V2 런타임 동작 보장 대상이 아니며, 실제 실행 시에는 V2 계약(`selectors`, `onValueChange`, `placeholder`, `meta.source: selector | external`)만 사용해야 한다.

## 6. 개발 경고 정책 (V2)

- `selectors`가 누락되거나 빈 배열이면 개발 환경에서 경고를 1회 출력한다.
- runtime plugin `type`이 등록된 selector와 매칭되지 않으면 개발 환경에서 경고를 1회 출력한다.
- duplicate selector type은 first-wins로 처리하고, 중복 type당 경고를 1회만 출력한다.
- deprecated 입력(`selectorsProps`, `onChange`)은 런타임에서 무시되고 개발 경고만 제공한다.

## 7. 공개 보조 API 활용 예시

```tsx
import {
  createKeywordSelector,
  createRegionSelector,
  createSelectorResolutionWarningContext,
  resolveSelectorsWithPolicy,
  validateSelectorTypeUniqueness,
  type RegionDataSource,
} from 'compsable-search'

const regionDataSource: RegionDataSource = {
  findAllSidos: () => [{ displayName: '서울특별시', name: '서울특별시', code: '11' }],
  findAllSigungus: (_sidoCode) => [],
  findAllEupmyeondongs: (_sigunguCode) => [],
}

const selectors = [
  createRegionSelector('region-main', {
    ...regionDataSource,
    options: { placeholder: '지역 선택' },
  }),
  createRegionSelector('region-fallback', {
    ...regionDataSource,
    options: { placeholder: '백업 지역 선택' },
  }),
  createKeywordSelector('keyword-main', {
    options: { placeholder: '키워드 선택', label: '키워드 입력' },
  }),
]

const duplicates = validateSelectorTypeUniqueness(selectors)
const warningContext = createSelectorResolutionWarningContext()
const resolved = resolveSelectorsWithPolicy(selectors, { warningContext })

console.log(duplicates) // [{ selectorType: 'region', count: 2 }]
console.log(resolved.regionSelector?.id) // region-main (first-wins)
```
