# 0.3.0 마이그레이션 노트

## 메타

- 대상 버전: `0.2.x -> 0.3.x`
- 문서 버전: `v0.3`
- 마지막 갱신: `2026-02-28`

## 1. 변경 요약

- 상태/이벤트 축이 `onChange` 중심에서 `value/defaultValue/onValueChange` 중심으로 확장되었습니다.
- selector 전달 기본 경로가 `selectorsProps`에서 `selectors`로 이동했습니다.
- selector 라벨 표준 필드가 `placeHolder`에서 `placeholder`로 정리되었습니다.
- 레거시 입력(`selectorsProps`)을 즉시 이관하기 위한 `adaptLegacySelectorsProps`가 제공됩니다.

## 2. 0.2.x -> 0.3 체크리스트

- [ ] `ComposableSearch`에 `onChange`만 연결한 코드를 `onValueChange` 중심으로 전환했다.
- [ ] controlled가 필요한 화면은 `value + onValueChange`로 전환했다.
- [ ] uncontrolled 화면은 `defaultValue + onValueChange`로 전환했다.
- [ ] `selectorsProps` 직접 전달 코드를 `selectors`로 전환했다.
- [ ] selector 생성을 `createRegionSelector`/`createKeywordSelector`로 통일했다.
- [ ] `placeHolder`를 `placeholder`로 치환했다.
- [ ] 점진 이관 구간에서는 `adaptLegacySelectorsProps`를 통해 기존 `selectorsProps`를 연결했다.
- [ ] 중복 selector type 입력(first-wins) 동작을 QA 시나리오에 포함했다.
- [ ] `onValueChange` 메타(`source`, `selectorType`, `selectorId`)를 로깅/분석 코드에서 활용하도록 반영했다.

## 3. 코드 매핑표 (0.2.x -> 0.3)

| 0.2.x 패턴 | 0.3 권장 패턴 | 비고 |
| --- | --- | --- |
| `onChange={(items) => ...}` | `onValueChange={(nextValue, meta) => ...}` | `onChange`는 deprecated이며 하위 호환 유지 |
| `selectorsProps={[...]}` | `selectors={[...]}` | `selectorsProps`는 deprecated |
| `type: 'region'` 객체를 직접 배열에 배치 | `createRegionSelector('region-main', regionProps)` | selector `id`를 명시적으로 관리 |
| `type: 'keyword'` 객체를 직접 배열에 배치 | `createKeywordSelector('keyword-main', keywordProps)` | selector `id`를 명시적으로 관리 |
| `options.placeHolder` | `options.placeholder` | `placeHolder`는 deprecated |
| 레거시 구조 유지 필요 시 수동 매핑 | `adaptLegacySelectorsProps(legacySelectorsProps)` | 점진 이관 시 권장 |

## 4. Before/After 예시

### Before (0.2.x)

```tsx
<ComposableSearch
  onChange={(selectedItems) => {
    console.log(selectedItems)
  }}
  selectorsProps={[
    {
      type: 'region',
      findAllSidos,
      findAllSigungus,
      findAllEupmyeondongs,
      options: {
        placeHolder: '지역 선택',
      },
    },
    {
      type: 'keyword',
      options: {
        placeHolder: '키워드 선택',
      },
    },
  ]}
/>
```

### After (0.3 권장)

```tsx
import {
  ComposableSearch,
  createKeywordSelector,
  createRegionSelector,
} from './src/components'

const selectors = [
  createRegionSelector('region-main', {
    findAllSidos,
    findAllSigungus,
    findAllEupmyeondongs,
    options: {
      placeholder: '지역 선택',
    },
  }),
  createKeywordSelector('keyword-main', {
    options: {
      placeholder: '키워드 선택',
    },
  }),
]

<ComposableSearch
  defaultValue={[]}
  selectors={selectors}
  onValueChange={(nextValue, meta) => {
    console.log(nextValue, meta)
  }}
/>
```

### After (점진 이관)

```tsx
import {
  ComposableSearch,
  adaptLegacySelectorsProps,
  type ComposableSearchProps,
} from './src/components'

const legacySelectorsProps: NonNullable<ComposableSearchProps['selectorsProps']> = [
  {
    type: 'region',
    findAllSidos,
    findAllSigungus,
    findAllEupmyeondongs,
    options: {
      placeHolder: '지역 선택',
    },
  },
  {
    type: 'keyword',
    options: {
      placeHolder: '키워드 선택',
    },
  },
]

<ComposableSearch
  selectors={adaptLegacySelectorsProps(legacySelectorsProps)}
  onValueChange={(nextValue, meta) => {
    console.log(nextValue, meta)
  }}
/>
```

## 5. 하위 호환(compat) 정책

- `selectorsProps`, `onChange`, `placeHolder`는 `0.3.x` 동안 하위 호환으로 유지됩니다.
- compat 제거 목표 버전은 **TBD**입니다.
- 제거 시점 확정 전까지는 deprecation 안내와 대체 경로(`selectors`, `onValueChange`, `placeholder`)를 함께 유지합니다.
