# 0.x Breaking 마이그레이션 노트 (V2 Generic Selector)

## 메타

- 대상 버전: `legacy 0.x -> V2 0.x`
- 문서 버전: `v2-breaking`
- 마지막 갱신: `2026-03-02`

## 1. 변경 요약

V2는 0.x 라인에서의 breaking 전환입니다. selector 구성과 상태 변경 계약을 Generic Selector 중심으로 정리했습니다.

- selector 입력 경로: `selectors`
- 상태 변경 이벤트: `onValueChange(nextValue, meta)`
- placeholder 표준 키: `placeholder`
- Region 데이터소스: sync/async(`MaybePromise`) + optional `context.signal`

## 2. Breaking 변경 매핑

| 레거시 패턴 | V2 패턴 | 영향 |
| --- | --- | --- |
| `selectorsProps={[...]}` | `selectors={[...]}` | selector 구성 방식 변경 |
| `onChange={(items) => ...}` | `onValueChange={(nextValue, meta) => ...}` | 이벤트 시그니처 변경 |
| `placeHolder` | `placeholder` | 옵션 키 표준화 |
| `meta.source === 'region' | 'keyword'` | `meta.source === 'selector' | 'external'` 중심 처리 | 메타 해석 규칙 변경 |

## 3. 체크리스트

- [ ] `selectorsProps` 전달을 제거하고 `selectors`로 전환했다.
- [ ] `onChange`를 `onValueChange`로 전환했다.
- [ ] `placeHolder`를 `placeholder`로 치환했다.
- [ ] 로깅/분석 코드가 `meta.reason`, `meta.source`, `meta.selectorType`를 처리하도록 갱신됐다.
- [ ] Region 데이터소스가 sync/async 모두에서 동일 타입 계약을 만족하는지 검증했다.

## 4. Before / After

### Before (legacy)

```tsx
<ComposableSearch
  onChange={(selectedItems) => {
    console.log(selectedItems)
  }}
  selectorsProps={[
    {
      type: 'region',
      findAllSidos,
      findAllSigungus,
      findAllEupmyeondongs,
      options: { placeHolder: '지역 선택' },
    },
    {
      type: 'keyword',
      options: { placeHolder: '키워드 선택' },
    },
  ]}
/>
```

### After (V2 Generic Selector)

```tsx
import {
  ComposableSearch,
  createSelector,
  type ComposableSearchProps,
  type SelectionItem,
  type SelectorDriver,
} from 'compsable-search'

interface DemoSelectorProps {
  options?: { placeholder?: string }
  items: Array<{ id: string; label: string }>
}

const regionDriver: SelectorDriver<DemoSelectorProps, 'region', SelectionItem> = {
  type: 'region',
  getTriggerLabel: (props) => props.options?.placeholder ?? '지역 선택',
  loadItems: async (_context, props) =>
    props.items.map((item) => ({
      id: item.id,
      displayName: item.label,
      selectorId: 'region-main',
      selectorType: 'region',
    })),
  renderPanel: () => null,
}

const keywordDriver: SelectorDriver<DemoSelectorProps, 'keyword', SelectionItem> = {
  type: 'keyword',
  getTriggerLabel: (props) => props.options?.placeholder ?? '키워드 선택',
  loadItems: (_context, props) =>
    props.items.map((item) => ({
      id: item.id,
      displayName: item.label,
      selectorId: 'keyword-main',
      selectorType: 'keyword',
    })),
  renderPanel: () => null,
}

type SelectorEntry = NonNullable<ComposableSearchProps['selectors']>[number]

const selectors: NonNullable<ComposableSearchProps['selectors']> = [
  createSelector({
    id: 'region-main',
    type: 'region',
    props: {
      options: { placeholder: '지역 선택' },
      items: [{ id: '11', label: '서울특별시' }],
    },
    driver: regionDriver,
  }) as unknown as SelectorEntry,
  createSelector({
    id: 'keyword-main',
    type: 'keyword',
    props: {
      options: { placeholder: '키워드 선택' },
      items: [{ id: 'kw:원룸', label: '원룸' }],
    },
    driver: keywordDriver,
  }) as unknown as SelectorEntry,
]

<ComposableSearch
  defaultValue={[]}
  selectors={selectors}
  onValueChange={(nextValue, meta) => {
    console.log(meta.reason ?? 'replace', meta.source, meta.selectorType)
    console.log(nextValue)
  }}
/>
```
