# CI/CD 체크리스트

## 1. 파이프라인 기본 점검

- 트리거 조건(PR/Push/Tag)이 명확한가.
- `lint`, `build`, `test` 단계가 포함됐는가.
- 단계 실패 시 즉시 중단되도록 구성됐는가.

## 2. 아티팩트 관리

- 빌드 산출물이 버전/커밋 기준으로 추적 가능한가.
- 아티팩트 보관 기간과 접근 권한이 정의됐는가.
- 재현 가능한 빌드 절차가 문서화됐는가.

## 3. 보안/신뢰성

- 시크릿이 코드/로그에 노출되지 않는가.
- 외부 액션/의존성 버전 고정 여부를 확인했는가.
- 병렬 실행/재시도/타임아웃 정책이 정의됐는가.

## 4. 배포 게이트

- 배포 전 필수 검증 단계가 모두 통과되는가.
- 수동 승인 단계가 필요한 환경(예: production)을 분리했는가.
- 실패 시 롤백 또는 배포 중단 규칙이 있는가.

## 5. 운영 연계

- 배포 후 헬스체크/모니터링 검증이 포함됐는가.
- 실패 알림 채널(이메일/슬랙 등)이 정의됐는가.
- 릴리스 리포트와 변경 이력이 남는가.
