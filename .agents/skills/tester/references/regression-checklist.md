# 회귀 검증 체크리스트

## 1. 기본 상태 점검

- 의존성 설치가 정상인가.
- `npm run lint`가 통과하는가.
- `npm run build`가 통과하는가.
- 테스트 스크립트가 있으면 실행 결과가 통과하는가.

## 2. 기능 회귀 점검

- 기존 핵심 사용자 흐름이 유지되는가.
- 변경 기능과 인접 기능의 충돌이 없는가.
- 오류 처리와 예외 케이스 동작이 유지되는가.

## 3. API/컴포넌트 호환성 점검

- 공개 API 시그니처 변경이 의도된 범위 내인가.
- 기본값, 이벤트 계약, 타입 제약이 유지되는가.
- 하위 호환성 깨짐이 있으면 명시됐는가.

## 4. 비기능 점검

- 성능/번들 크기/렌더링 비용 악화가 없는가.
- CSS 누수 및 전역 부작용이 없는가.
- 런타임 전역 수정/강제 폴리필이 없는가.

## 5. 배포 관점 점검

- npm 배포 산출물 품질에 영향이 없는가.
- 문서/PRD와 구현 동작이 불일치하지 않는가.
- 릴리스 차단 이슈(Release Blocker)가 정리됐는가.
