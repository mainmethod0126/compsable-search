# 고난도 문제 해결 플레이북

## 1. 문제 정식화

- 증상을 관측 가능한 사실로 분리한다.
- 기대 동작과 실제 동작의 차이를 한 문장으로 정의한다.
- 성공 기준을 측정 가능 지표로 고정한다.

## 2. 재현과 계측

- 최소 재현 경로를 확보한다.
- 로그, 프로파일링, 입력 데이터 샘플을 확보한다.
- 동일 조건에서 반복 실행해 변동성을 확인한다.

## 3. 가설 검증

- 가능한 원인 가설을 2~3개로 제한한다.
- 각 가설마다 반증 조건을 먼저 정의한다.
- 가장 비용이 낮은 실험부터 실행한다.

## 4. 패치 설계

- 최소 변경으로 목표를 달성하는 안을 우선 채택한다.
- 부작용이 예상되는 경계 조건을 목록화한다.
- 필요 시 단계적 적용(Feature flag, 점진 배포)을 사용한다.

## 5. 검증과 문서화

- 기능 테스트, 회귀 테스트, 성능 비교를 수행한다.
- 변경 전후 수치를 기록한다.
- 재발 방지 항목(테스트/가드레일/모니터링)을 남긴다.
