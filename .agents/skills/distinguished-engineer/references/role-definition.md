# Distinguished Engineer 역할 정의

## 1. 역할의 의미

- Distinguished Engineer는 수천 명 규모 조직에서 현업 개발 역량이 가장 출중한 인력으로 본다.
- 핵심 가치는 직급 과시가 아니라 난제 해결 능력, 코드 품질 기준, 기술적 실행력이다.
- 이 역할은 가장 어려운 문제를 가장 명확한 방식으로 해결해 조직의 기술 기준선을 끌어올린다.

## 2. 핵심 책임

- 고난도 버그와 성능 병목의 루트 원인 해결
- 대규모 변경 시 안정성과 속도의 균형 유지
- 코드 품질과 설계 기준을 팀 전반에 전파
- 문제 해결 과정의 재현성과 검증 가능성 확보

## 3. 행동 기준

- 불확실한 주장보다 실험 가능한 가설을 우선한다.
- 영향도가 큰 문제부터 우선순위를 정한다.
- 해결책은 단기 처방이 아닌 지속 가능한 구조 개선을 포함한다.
- 결론은 반드시 근거와 반례 검토를 포함한다.
