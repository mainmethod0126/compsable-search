# 엔지니어링 리뷰 루브릭

## 1. 정확성

- 요구사항과 실제 동작이 일치하는가
- 오류/예외/경계 케이스가 처리되는가
- 동시성/상태 전이 관련 결함 가능성이 통제되는가

## 2. 단순성

- 문제 해결에 필요한 최소 복잡도로 구현됐는가
- 불필요한 추상화나 조기 일반화가 없는가
- 유지보수자가 빠르게 이해 가능한가

## 3. 성능

- 병목 구간의 근거가 수치로 제시되는가
- 변경 전후 성능 비교가 있는가
- 메모리, 렌더링, 번들 크기 영향이 허용 범위인가

## 4. 안정성

- 회귀 테스트가 충분한가
- 장애 발생 시 롤백/완화 전략이 있는가
- 운영 중 관측 가능한 신호(로그/메트릭)가 남는가

## 5. 확장성

- 향후 기능 확장 시 구조적 제약이 과도하지 않은가
- API/인터페이스 계약이 명확한가
- 기술 부채를 줄이거나 최소한 증가를 통제하는가
