# 인테이크/트리아지 체크리스트

## 1. 문제 정의

- 요청이 해결해야 할 핵심 문제를 한 문장으로 정의했는가.
- 기대 결과와 완료 조건이 명확한가.
- 범위 밖 항목을 분리했는가.

## 2. 우선순위 판단

- 사용자 영향도가 높은가.
- 릴리스/운영 리스크가 큰가.
- 선행 의존성과 차단 요소가 있는가.

## 3. 라우팅 판단

- 작업 목적에 맞는 주 담당 에이전트를 선택했는가.
- 협업 에이전트와 순서를 지정했는가.
- 각 에이전트 입력 자료가 준비됐는가.

## 4. 실행 준비도

- 작업을 독립 실행 가능한 단위로 분해했는가.
- 검증 방법(명령/수동 절차)이 정의됐는가.
- 보고 형식과 산출물 경로가 정의됐는가.

## 5. 통제 포인트

- 중간 점검 시점이 정의됐는가.
- 실패 시 에스컬레이션/재배정 기준이 있는가.
- Release Blocker 관리 방식이 정의됐는가.
