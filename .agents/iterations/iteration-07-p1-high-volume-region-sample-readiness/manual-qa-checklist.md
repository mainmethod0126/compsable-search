# Iteration 07 수동 QA 체크리스트

## 메타
- 이터레이션: `iteration-07-p1-high-volume-region-sample-readiness`
- 관련 Task: `T-164`
- 갱신일: `2026-02-19`
- 대상 프로파일: `small`, `medium`, `large`

## 1. 실행 환경
- 데스크톱: `>=1024px`
- 모바일: `<=768px`
- 브라우저: Chromium 계열(기본), 추가 브라우저는 후속 확장

## 2. 공통 시나리오
- [ ] 프로파일 전환(`small -> medium -> large`)이 앱 재시작 없이 반영된다.
- [ ] 지역 패널 열기/닫기가 정상 동작한다.
- [ ] 시/도 -> 시/군/구 -> 읍/면/동 선택 흐름이 정상 동작한다.
- [ ] 선택 해제(동일 항목 재클릭/재체크)가 정상 동작한다.
- [ ] `전체` 선택과 상세 선택의 상호 배타가 유지된다.
- [ ] `전체 삭제`로 칩/체크 상태가 동시에 초기화된다.
- [ ] 전환 직후 이전 프로파일 선택 상태가 남지 않는다.

## 3. 데스크톱 추가 점검
- [ ] 3열 레이아웃에서 가로 overflow가 없다.
- [ ] 대량 리스트에서 스크롤로 하위 항목 접근이 가능하다.
- [ ] 이벤트 로그와 성능 기준선 패널이 동시에 확인 가능하다.

## 4. 모바일 추가 점검
- [ ] 컬럼이 1열로 전환되고 조작 차단이 없다.
- [ ] 스크롤 영역에서 터치 스크롤/체크가 정상 동작한다.
- [ ] 라벨/버튼 텍스트가 겹치거나 절단되지 않는다.

## 5. 증적 수집 규칙
- 실패 시 반드시 아래를 첨부한다.
  - 스크린샷 1장 이상 (`{profile}-{viewport}-{scenario}.png`)
  - 콘솔/네트워크 로그(있을 경우)
  - 재현 순서(최소 3단계)
- 성공 점검도 프로파일별 완료 시각과 담당자 이니셜을 기록한다.
