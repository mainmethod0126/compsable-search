# Iteration 09 사용성/접근성 검증

- 검증 방식: FE/QA 내부 워크스루

## 1. 검증 시나리오
1. 입력 시나리오
- `수`, `서` 부분 입력으로 후보가 즉시 표시되는지 확인

2. 선택 시나리오
- 후보 클릭 시 조건 칩이 1회만 추가되는지 확인
- 기존 선택된 동일 항목 클릭 시 토글 동작이 유지되는지 확인

3. 해제 시나리오
- 칩 개별 삭제/전체 삭제 시 `onChange` payload가 동기화되는지 확인

## 2. 카피/접근성 확정
- 입력 라벨: `지역 검색`
- 빈 결과 카피: `일치하는 지역이 없습니다.`
- 안내 카피: `지역명을 입력하면 시/도, 시/군/구, 읍/면/동 미리보기를 제공합니다.`
- 입력 접근성: `<label>` + `aria-label` 동시 제공
- 미리보기 접근성: `<button type="button">` 기반 키보드 포커스 가능

## 3. 잔여 이슈
- ArrowUp/ArrowDown 기반 리스트 키보드 내비게이션은 후속 최적화 항목으로 남긴다.
