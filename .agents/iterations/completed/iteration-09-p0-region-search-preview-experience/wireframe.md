## 1. 배치 계약
- `cs-selector-area` 바깥 아래(다음 형제 영역)에 지역 검색 입력 컴포넌트를 배치한다.
- 지역 검색 입력은 `cs-detailed-area` 외부에 위치해야 한다.
- selector 트리거(`지역 선택`, `키워드 선택`) 영역 바로 아래에서 시각적으로 노출한다.

## 2. 상태별 화면
1. 기본 상태
- 라벨: `지역 검색`
- 플레이스홀더: `시/도, 시/군/구, 읍/면/동 검색`
- 안내 카피: `지역명을 입력하면 시/도, 시/군/구, 읍/면/동 미리보기를 제공합니다.`

2. 포커스 상태
- 입력 필드 경계 강조(`focus-within`)
- 키보드 입력 즉시 미리보기 후보 갱신

3. 입력 중(결과 있음)
- 리스트 아이템은 `경로 미리보기` 형식으로 노출
- 예시:
  - `서울특별시 > 광진구`
  - `충청남도 > 서산시`
  - `경기도 > 수원시 장안구 > 조원동`

4. 입력 중(결과 없음)
- 카피: `일치하는 지역이 없습니다.`

## 3. 반응형 기준
- 데스크톱: 검색 박스 최대 폭 `460px`
- 모바일(`max-width: 768px`): 검색 박스 폭 `100%`
- 미리보기 목록은 세로 스크롤만 허용한다.
