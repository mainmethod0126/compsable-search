# Iteration 01 릴리스 런북

## 1. 사전 점검(Pre-release)
- 코드 게이트:
  - `npm test`
  - `npm run lint`
  - `npm run build`
- 확인 항목:
  - selector 순서 보존(`region -> keyword`)
  - region 상세 패널 토글(open/closed)
  - 상세 패널 콘텐츠 주입(3컬럼)
  - 선택 칩 추가/삭제/전체삭제
  - 전체/상세 지역 상호배타 규칙

## 2. 모니터링 포인트(Observability)
- 사용자 시그널:
  - region 트리거 클릭 후 상세 패널 렌더 성공률
  - 읍/면/동 체크 토글 후 칩 반영 성공률
- 품질 시그널:
  - 빌드/린트 실패율
  - React key/console 경고 재발 여부
- 임계값:
  - 저장소 단위 표준이 미정이므로 `TBD` (다음 이터레이션에서 확정)

## 3. 배포 후 점검(Post-release)
- 수동 시나리오:
  - 시/도 -> 시/군/구 -> 읍/면/동 선택 흐름
  - 동일 항목 재선택 시 토글 제거
  - 전체 지역 선택 후 상세 선택 시 상호배타 적용
  - 전체 삭제 버튼 상태 전환(disabled/enabled)

## 4. 롤백 절차
- 조건:
  - 빌드/린트 게이트 실패
  - 핵심 시나리오(토글/선택/삭제) 회귀 확인
- 절차:
  1. 직전 안정 커밋으로 배포 버전 되돌림
  2. 회귀 재현 테스트(`npm test`)로 실패 케이스 고정
  3. 원인 패치 후 빌드/린트/테스트 재검증
