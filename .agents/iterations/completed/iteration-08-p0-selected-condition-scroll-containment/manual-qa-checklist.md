# Iteration 08 수동 QA 체크리스트

## 1. 데스크톱 시나리오 (`>=1024px`)
- [ ] 지역/키워드 조합으로 칩을 30개 이상 누적했을 때 선택 조건 영역 높이가 `144px` 상한 내에서 유지된다.
- [ ] 선택 조건 영역 내부 세로 스크롤로 하단 칩까지 탐색 가능하다.
- [ ] 스크롤 상태에서 임의 칩의 `삭제` 버튼 클릭이 정상 동작한다.
- [ ] 스크롤 상태에서 `전체 삭제` 버튼이 정상 동작하고 칩이 모두 제거된다.
- [ ] 삭제 직후 상세 패널 조작(지역 선택/키워드 입력)이 차단되지 않는다.

## 2. 모바일 시나리오 (`<=768px`)
- [ ] 칩 다량 상태에서 선택 조건 영역 높이가 `112px` 상한 내에서 유지된다.
- [ ] 내부 세로 스크롤 동작 중에도 탭/클릭으로 칩 삭제가 가능하다.
- [ ] 선택 조건 영역이 상세 패널 영역을 과도하게 밀어내지 않는다.
- [ ] `전체 삭제` 이후 버튼 비활성/빈 상태 전환이 정상 반영된다.

## 3. 계약 점검
- [ ] 개별 삭제 후 `onChange` payload에서 삭제한 조건 ID가 제거된다.
- [ ] `전체 삭제` 후 `onChange` payload가 빈 배열(`[]`)로 전달된다.
- [ ] 접근성 라벨(`{조건명} 삭제`)이 스크롤 도입 후에도 유지된다.
