## 문제 정의
### 현재 동작
- `src/components/RegionDetailPanel.tsx`는 `시/도`, `시/군/구`, `읍/면/동` 3컬럼 선택 UI만 제공하고, 지역명 검색 입력 및 미리보기 UI가 없다.
- 사용자는 계층 클릭(시/도 -> 시/군/구 -> 읍/면/동)으로만 조건을 추가할 수 있고, 부분 일치 검색으로 바로 후보를 찾을 수 없다.
- `src/components/SelectableRegionColumn.tsx` 상단에는 제목/전체 토글만 존재해, "시/도 영역 상단"에 검색 입력을 배치할 확장 포인트가 없다.

### 기대 동작
- "시/도" 영역 상단 근처에 지역 검색 입력 박스를 노출한다.
- 입력 박스는 별도 컴포넌트로 분리하고, 좌측 SVG 아이콘 슬롯을 지원한다.
- 입력값과 부분 일치하는 지역(시/도, 시/군/구, 읍/면/동)을 즉시 미리보기 목록으로 표시한다.
- 미리보기 항목은 경로 문자열(`서울특별시 > 광진구`, `충청남도 > 서산시`, `경기도 > 수원시 장안구 > 조원동`) 형태로 표시한다.
- 미리보기 클릭 시 기존 선택 정책(`selectionPolicy`)과 콜백 계약(`onChange`, `onSelectedEupmyeondong`)을 유지한 채 "선택된 조건"에 반영한다.

### 재현 조건
- 환경: `React 19 + Vite + Vitest` (`package.json` 기준)
- 절차:
1. `ComposableSearch`에서 지역 패널을 연다.
2. 현재는 수동 컬럼 탐색만 가능하고, 지역명 부분 검색 UI/결과가 없다.

### 영향 범위
- UI: `RegionDetailPanel`, `SelectableRegionColumn`, 신규 검색 입력 컴포넌트, `ComposableSearch.css`
- 도메인 로직: 지역 트리 평탄화/부분 일치 검색/미리보기->선택 조건 매핑 로직
- 테스트: `ComposableSearch.test.tsx` 및 신규 검색 로직 단위 테스트
- 콜백/회귀: 기존 `callbackPipeline`, `selectionPolicy` 계약 유지 필요

## 권장 해결안
- 선택 대안: `A`
- 선택 근거:
- 현재 요구는 "부분 일치 + 경로 미리보기 + 클릭 선택"이 핵심이라 퍼지 검색 라이브러리 없이도 충분히 달성 가능하다.
- 검색 모델을 순수 함수로 분리하면 TDD 적용과 회귀 검증이 쉽고, UI 컴포넌트 책임을 분리할 수 있다.
- 기존 선택 정책(`toggleRegionCondition`)을 재사용해 동작 일관성을 유지할 수 있다.
- 기각한 대안과 사유:
- `B`: 입력마다 데이터 소스를 재순회하므로 대용량 프로파일에서 지연 위험이 크다.
- `C`: 현재 요구 대비 복잡도/의존성 비용이 과도하다.

## 테스트 및 검증 계획
### Unit
- 검색 인덱스 생성 시 시/도/시군구/읍면동 경로 라벨이 정확히 생성되는지 검증
- 부분 일치 필터가 한글 부분 문자열(`수`, `서`)을 올바르게 매칭하는지 검증
- 미리보기 항목 클릭 시 생성되는 `SelectedRegionCondition` 매핑(레벨별)이 기대값인지 검증

### Integration
- 지역 패널 오픈 후 시/도 컬럼 상단에 검색 입력과 아이콘이 노출되는지 검증
- 검색어 입력 시 미리보기 목록 렌더링/비노출 상태 전환(빈 문자열, 결과 없음) 검증
- 미리보기 클릭 시 선택 칩 추가 및 `onChange`, `onSelectedEupmyeondong` 호출 계약 검증

### Regression
- 기존 지역 선택 플로우(컬럼 클릭/전체 선택/상호배타/칩 삭제) 테스트 재실행
- 키워드 입력 기능 회귀 영향 없음 확인 (`keywordInputModel`, `ComposableSearch` 기존 테스트)

### 필요 시 추가
- 성능: large 프로파일에서 연속 입력 시 UI 멈춤/지연 여부 수동 스모크
- 보안: 미리보기 텍스트 렌더링에서 `dangerouslySetInnerHTML` 미사용 유지 확인

## 배포 / 롤백 / 운영 관측
### 배포 전략
- 기능 구현 후 테스트 게이트(`npm run test`, `npm run lint`) 통과 시 머지
- 라이브러리 변경은 `minor` 범위로 릴리스 노트에 "지역 검색 미리보기" 추가

### 롤백 전략
- 트리거: 회귀 테스트 실패, 대량 데이터 입력 지연, 선택 조건 오동작
- 절차:
1. 기능 도입 커밋 revert
2. 회귀 테스트 재실행
3. 이전 릴리스 태그 재배포

### 운영 관측
- 핵심 지표: 검색 입력 후 결과 렌더링 지연 체감(수동), 미리보기 클릭 후 칩 반영 성공률(테스트)
- 로그/트레이싱 포인트: 콜백 에러(`callbackPipeline`의 `CALLBACK_ERROR_PREFIX`) 발생 여부
- 알람 조건: 테스트 파이프라인 실패 또는 콜백 에러 로그 증가
