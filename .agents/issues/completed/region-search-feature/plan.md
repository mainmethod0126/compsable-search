## 문제 정의
### 현재 동작
- `RegionDetailPanel`은 시/도, 시/군/구, 읍/면/동 컬럼 탐색만 제공하며 지역명 검색 입력/미리보기가 없다.
- 검색 입력 전용 컴포넌트가 없고, 좌측 아이콘을 수용하는 입력 UI 계약도 정의되어 있지 않다.
- 선택 조건 추가는 체크박스 토글 중심으로 동작하며 검색 결과 클릭 경로가 없다.

### 기대 동작
- `지역 검색` 입력 박스가 `시/도` 영역 상단에 배치되어야 한다.
- 입력 박스 좌측에 지역 의미의 SVG 아이콘을 배치할 수 있어야 한다.
- 입력 UI는 별도 컴포넌트로 분리되어야 하며, 좌측 아이콘 주입과 미리보기 목록 표시/선택 기능을 지원해야 한다.
- 지역명을 입력하면 시/도/시군구/읍면동 전체 범위에서 부분 일치하는 결과를 미리보기로 즉시 보여줘야 한다.
- 미리보기는 계층 경로 문자열(예: `서울 > 광진구`, `충남 > 서산시`, `경기도 > 수원시 장안구 > 조원동`)로 렌더링되어야 한다.
- 미리보기 항목 클릭 시 해당 지역 조건이 `선택된 조건` 영역에 추가되어야 한다.

### 재현 조건
- `ComposableSearch`를 region selector 포함 상태로 렌더링하고 지역 패널을 연다.
- 검색 입력에 `수`, `서`를 입력한다.
- 미리보기 노출, 경로 표시 포맷, 클릭 후 조건 칩 추가를 확인한다.
- 입력 좌측 SVG 아이콘 렌더링 여부와 `시/도` 상단 배치를 확인한다.

### 영향 범위
- `src/components/RegionDetailPanel.tsx` (검색 컴포넌트 연결, 선택 핸들러 연동)
- `src/components/ComposableSearch.css` (입력/아이콘/미리보기/반응형 스타일)
- 신규 컴포넌트 파일(예: `src/components/RegionSearchInput.tsx`) 및 스타일 클래스
- 신규 검색 유틸(예: `src/components/regionSearchIndex.ts`)
- `src/components/ComposableSearch.test.tsx` 및 신규 컴포넌트/유틸 테스트

## 성공 기준 / 비목표
### 성공 기준
- [ ] `지역 검색` 입력 박스가 `시/도` 영역 상단에 배치된다.
- [ ] 입력 박스 좌측에 SVG 아이콘이 렌더링되고 레이아웃 깨짐이 없다.
- [ ] 입력 박스가 별도 컴포넌트로 분리되어 재사용 가능한 아이콘 주입 계약을 가진다.
- [ ] 입력값 부분 일치 검색(`수`, `서`)이 시/도/시군구/읍면동 전 범위에서 즉시 동작한다.
- [ ] `수` 입력 시 `수원` 계열 결과가, `서` 입력 시 `서울특별시`/`서산` 계열 결과가 미리보기에 노출된다.
- [ ] 미리보기 항목이 계층 경로 포맷으로 노출된다.
- [ ] 미리보기 클릭 시 조건 칩이 추가되고 기존 `onChange`/상호배타 규칙 회귀가 없다.

### 비목표
- 초성/오타 교정/유사도 랭킹 기반 고급 검색
- 서버 API 기반 비동기 자동완성
- 검색 결과 virtualization 도입

## 권장 해결안
- 선택 대안: `A`
- 선택 근거:
  - 이슈의 명시 요구인 `별도 컴포넌트`, `좌측 SVG 아이콘`, `미리보기 기능`을 동시에 만족한다.
  - 검색 UI를 독립 컴포넌트로 분리하면 `RegionDetailPanel`의 책임 증가를 억제하고 테스트를 분리할 수 있다.
  - 기존 선택 정책(`toggleRegionCondition`)과 콜백 계약을 유지한 채 연결 가능하다.
- 기각한 대안과 사유:
  - `B`: 단기 구현은 빠르지만 구조 품질과 재사용성 요구를 충족하지 못한다.
  - `C`: 외부 의존성 및 통합 비용이 크고 현재 범위 대비 과도하다.

## 테스트 및 검증 계획
### Unit
- `regionSearchIndex`의 검색 결과/경로 포맷/레벨 매핑 검증
- `RegionSearchInput`에서 `leftIcon` 렌더링, 입력 변경, preview 렌더링, 항목 선택 이벤트 검증
- 검색 결과를 `SelectedRegionCondition`으로 변환하는 규칙 검증

### Integration
- `ComposableSearch`에서 `지역 검색` 입력 -> preview 표시 -> 항목 클릭 -> `선택된 조건` 칩 추가 흐름 검증
- `수`/`서` 입력 시 부분일치 결과(`수원`, `서울특별시`, `서산`)가 즉시 미리보기에 나타나는지 검증
- 검색 입력이 `시/도` 영역 상단에 존재하는지 DOM 기준 확인
- 좌측 SVG 아이콘이 표시되고 입력/목록 정렬이 유지되는지 검증
- 기존 체크박스 선택과 검색 선택 혼합 시 `onChange` 및 상호배타 정책 유지 검증

### Regression
- 기존 `ComposableSearch.test.tsx` 핵심 시나리오(토글, 선택/해제, 전체 삭제, 콜백 계약) 전수 통과
- 대량 데이터(`large`)에서 검색 입력 지연/레이아웃 회귀 여부 점검

### 필요 시 추가
- 성능: 검색 입력 후 결과 렌더링 시간 측정(대량 데이터)
- 접근성: 입력/결과 버튼 포커스 이동, `aria-label` 점검
