# 지역 검색 기능

- "지역 검색" 입력 박스는 "시/도" 영역 상단쯤에 위치해야한다
- "지역 검색" 입력 박스 좌측에는 지역을 의미하는 아이콘을 넣을 수 있어야한다
- "지역 검색" 입력 박스는 별도의 컴포넌트로 만들어져야하며, 입력 박스 컴포넌트는 좌측에 svg 아이콘을 넣을 수 있어야하며 미리보기 기능일 지원해야한다
- "지역 이름"을 입력하면 하단에 일치하는 지역에 대한 미리보기가 생성되어야한다
- 예를들어 "수" 를 입력하면 "수원" 이 미리보기에 출력되어야하고 "서" 를 입력하면 "서울특별시", "서산" 등 시,군,구,읍,면,동을 가리지 않고 포함되는 지역 명이 바로 미리보기에 생성되어야한다 즉 부분일치하는 지역명이 미리보기로 보여야한다
- 미리보기는 "서울 > 광진구", "충남 > 서산시", "경기도 > 수원시 장안구 > 조원동" 이런식으로 미리보기가 보여야한다
- 미리보기 목록에서 원하는 지역을 클릭하면 "선택된 조건"에 추가되어야한다
- 위치는 cs-detailed-area 바깥 상단 좌측에 위치해야하며, cs-selector-area 바깥 아래(다음 형제 영역)에 위치해야한다
