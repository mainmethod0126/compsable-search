## 작업 내용
- 목표: 미리보기 클릭 결과를 기존 선택 정책과 콜백 계약에 안전하게 연결한다.
- 구현 항목: 미리보기 선택 -> `SelectedRegionCondition` 변환 로직을 적용한다. / `toggleRegionCondition` 정책과 중복/상호배타 규칙을 유지한다. / `dispatchRegionOnChange`, `dispatchRegionOnSelectedEupmyeondong` 호출 계약을 유지한다.
- 선행조건: `[T-176] 확정한다: 지역 검색 컴포넌트 디자인 핸드오프`, `[T-180] 구현한다: 지역 검색 입력과 미리보기 목록 UI`가 완료되어야 한다.

## 검증과 완료 조건
- 검증 방법(테스트/리뷰/지표): 코드 리뷰와 통합 테스트에서 콜백 호출 횟수/페이로드를 확인한다.
- 산출물: 연동 로직 코드, 콜백 계약 검증 코드
- 완료 정의(DoD): 미리보기 클릭으로 조건 칩이 정확히 1회 반영되고 기존 정책 회귀가 발생하지 않는다.
