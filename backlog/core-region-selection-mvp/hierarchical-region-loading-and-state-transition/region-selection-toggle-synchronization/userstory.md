## 수용 기준
- [ ] 시/군/구 컬럼의 `시/도 전체` 체크박스로 조건을 즉시 추가/해제할 수 있다.
- [ ] 시/군/구에서 `시/도 전체`를 체크한 경우 읍/면/동 컬럼에 동일한 `시/도 전체` 체크 옵션이 중복 노출되지 않는다.
- [ ] `시/도 전체`와 동일 시/도의 개별 시/군/구/읍/면/동 조건은 상호 배타 규칙에 맞춰 자동 정리된다.
- [ ] `부산광역시 해운대구`를 먼저 선택한 뒤 `부산광역시 전체`를 체크하면 기존 `해운대구` 조건(UI 체크/칩/내부 상태)이 즉시 해제된다.
- [ ] 토글 동기화 변경이 상위 Feature 수용 기준(FR-011, FR-019, FR-020)을 깨지 않음을 검증한다.
