## 작업 내용
- 목표: 상위 색상 인디케이터 변경이 기존 지역 선택 동작을 깨지 않으며, 하위 선택 기반 표시/원복이 안정적으로 동작함을 검증한다.
- 구현 항목: `서울특별시 > 강남구 > 역삼동` 선택 시 `서울특별시`/`강남구` 색상 표시 검증 케이스를 추가한다. / `역삼동` 해제 시 상위 표시 원복 검증 케이스를 추가한다. / `current`와 `has-descendant-selected`가 모두 파랑 계열일 때도 진하기/보더 스타일 차이로 구분되는지 검증 케이스를 추가한다. / 다중 하위 선택(예: `역삼동`, `논현동`)에서 마지막 하위 해제 전까지 상위 표시 유지 여부를 검증한다. / FR-016/FR-022/FR-019/FR-021 관련 회귀 시나리오를 함께 점검하고 결과를 PR/문서에 기록한다.
