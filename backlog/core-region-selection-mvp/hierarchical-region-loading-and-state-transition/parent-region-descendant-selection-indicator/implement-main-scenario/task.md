## 작업 내용
- 목표: 하위 선택이 존재할 때 상위 시/도/시/군/구 항목에 `has-descendant-selected` 시각 상태가 일관되게 표시되도록 구현한다.
- 구현 항목: 선택 조건에서 상위 경로별 하위 선택 존재 여부를 파생하는 로직을 추가한다. / 시/도 컬럼 item(`서울특별시`)과 시/군/구 컬럼 item(`강남구`)에 `has-descendant-selected` 스타일 클래스를 연결한다. / `역삼동`뿐 아니라 `강남구 전체` 해제 시에도 상위 표시가 즉시 원복되도록 상태 동기화를 적용한다. / `current`/직접 `selected`/`has-descendant-selected` 조합에서 우선순위 규칙을 코드와 스타일에 반영하고, `current`와 `has-descendant-selected`가 파랑 계열 내에서도 진하기/보더 스타일로 즉시 구분되도록 조정한다. / FR-016/FR-022/FR-019/FR-021 기존 동작과 공개 API 계약 호환성을 유지한다.
- 선행조건: [T-153] 정의한다: 하위 선택 상위 색상 인디케이터 범위와 상태 우선순위 완료
