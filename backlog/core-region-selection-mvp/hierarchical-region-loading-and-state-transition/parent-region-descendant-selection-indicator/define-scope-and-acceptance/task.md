## 작업 내용
- 목표: FR-023/AC-023을 기준으로 하위 선택 시 상위 항목에 적용할 색상 상태 모델과 우선순위 규칙을 확정한다.
- 구현 항목: `서울특별시 > 강남구 > 역삼동`과 `서울특별시 > 강남구 전체` 기준 기대 색상 상태를 컬럼별로 명세한다. / `default`, `current`, 직접 `selected`, `has-descendant-selected` 상태의 우선순위와 조합 규칙을 정의한다. / `current`와 `has-descendant-selected`가 동일 파랑 계열을 사용하더라도 진하기/채도 및 보더 스타일 차이로 즉시 구분되는 기준을 고정한다. / 하위 선택 해제 시 원복 조건과 예외 케이스(다중 하위 선택, 타 시/도 교차 선택, `전체` 선택)를 명시한다. / 하위 구현/검증 Task 입력 조건을 확정한다.
- 선행조건: `PRD.md`/`PRD.en.md`의 FR-023, AC-023 요구사항 확정
