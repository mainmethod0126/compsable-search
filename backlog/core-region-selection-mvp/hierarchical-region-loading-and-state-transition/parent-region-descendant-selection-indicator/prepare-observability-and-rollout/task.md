## 작업 내용
- 목표: 상위 색상 인디케이터 UX를 안전하게 배포하고 시각 회귀를 빠르게 탐지/복구할 수 있도록 운영 준비를 완료한다.
- 구현 항목: 릴리스 스모크 체크리스트에 `서울특별시 > 강남구 > 역삼동` 경로의 상위 색상 표시/원복 확인 항목을 추가한다. / `current`와 `has-descendant-selected`가 파랑 계열 내에서도 명확히 구분되는지(진하기/보더 스타일) 점검 항목을 추가한다. / 시각 회귀(상위 표시 누락, 잘못된 상태 잔존) 감지 기준과 triage 절차를 운영 문서에 반영한다. / 기존 상호 배타/자동 선택 금지/타이포그래피 체크 항목과 충돌하지 않도록 통합 점검 순서를 정리한다. / 롤백 조건과 실행 절차를 런북에 업데이트한다.
