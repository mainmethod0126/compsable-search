## 작업 내용
- 목표: 동일 시/도 범위에서 `시/도 전체`와 `개별 시/군/구`가 동시에 유지되지 않도록 선택 토글 로직을 구현하고, 시/군/구 목록 갱신 구간 전반에서 하위 자동 선택을 방지한다.
- 구현 항목: 충돌 조건 감지 로직 추가 및 기존 토글 파이프라인과 통합. / 선택 순서(전체->하위, 하위->전체) 모두에서 자동 해제 정책 적용. / `부산광역시 해운대구` 선선택 후 `부산광역시 전체` 체크 시 기존 `해운대구` 조건이 즉시 해제되도록 처리. / 시/도 선택 변경 및 `서울특별시 전체` 체크 후 해제 시 첫 시/군/구(`강남구`)로 current가 자동 fallback 되지 않도록 상태 전이를 제어한다. / 사용자의 시/군/구 명시 선택 전에는 읍/면/동 갱신을 트리거하지 않도록 동기화 규칙 적용. / 칩 렌더링 상태와 내부 선택 상태의 동기화 보장.
- 선행조건: [T-145] 정의한다: 시/도 전체-하위 시/군/구 상호 배타 범위와 수용 기준 완료
