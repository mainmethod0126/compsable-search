## 사용자 스토리
- As a: 검색 사용자인 최종 사용자
- I want: 입력한 텍스트가 정해진 규칙대로 토큰으로 확정되길 원한다.
- So that: 중복/불필요 공백/과도한 길이로 인한 검색 조건 오류 없이 일관된 결과를 얻을 수 있다.

## 수용 기준
- [ ] 입력값 정규화 규칙(앞뒤 공백 제거, 연속 공백 정리, 대소문자 정책)이 명시되고 구현에 적용된다.
- [ ] 중복 토큰 판별 기준(정규화 후 동일성 비교)이 적용되어 중복 추가가 차단된다.
- [ ] 토큰 최대 개수/토큰 길이 제한이 설정 가능하며 기본값과 예외 처리 정책이 문서화된다.
- [ ] 유효하지 않은 토큰 입력 시 사용자에게 안내 가능한 오류 상태가 정의된다.
