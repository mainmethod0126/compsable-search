## 작업 내용
- 목표: 체크박스 라벨 텍스트와 일반 지역 item 텍스트의 타이포그래피를 동일 기준으로 렌더링하도록 UI 스타일을 구현한다.
- 구현 항목: `cs-checkable-item`과 `cs-region-item`에 공통 타이포그래피 규칙을 적용해 브라우저 기본 `button`/`label` 폰트 차이를 제거한다. / `시/도 전체` 체크박스와 읍/면/동 체크박스 라벨 텍스트가 일반 item과 동일한 `font-family`, `font-size`, `font-weight`, `line-height`를 사용하도록 스타일을 정리한다. / `selected/current/hover` 상태 구분은 색상/배경/테두리 중심으로 유지하고 타이포그래피 속성 변경을 배제한다. / 기존 선택 토글 로직 및 공개 API 계약 호환성을 유지한다.
- 선행조건: [T-149] 정의한다: 지역 항목 타이포그래피 일관성 범위와 수용 기준 완료

- 산출물: 스타일/컴포넌트 코드 변경셋, 관련 문서 업데이트
