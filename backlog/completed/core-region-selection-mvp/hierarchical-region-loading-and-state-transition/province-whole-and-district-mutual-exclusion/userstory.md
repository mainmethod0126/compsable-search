## 수용 기준
- [x] 동일 시/도 범위에서 `시/도 전체`와 `개별 시/군/구`는 동시에 선택되지 않는다.
- [x] `시/도 전체` 선택 상태에서 개별 시/군/구를 선택하면 기존 `시/도 전체` 조건이 자동 해제된다.
- [x] 개별 시/군/구 선택 상태에서 `시/도 전체`를 선택하면 기존 개별 시/군/구 조건이 자동 해제된다.
- [x] `부산광역시 해운대구`를 먼저 선택한 뒤 `부산광역시 전체`를 선택하면 기존 `해운대구` 조건(UI 체크/칩/내부 상태)이 즉시 해제된다.
- [x] `서울특별시 전체`와 `서울특별시 강남구` 전환, `부산광역시 해운대구`와 `부산광역시 전체` 전환 모두에서 마지막 선택 조건만 칩/내부 상태에 남는다.
- [x] 시/군/구 컬럼에서 시/도 선택이 변경되거나 `서울특별시 전체`를 체크 후 해제해도 `강남구`가 자동 current/선택되지 않고, 사용자가 `강남구`를 직접 클릭하기 전까지 시/군/구/읍/면/동 하위 상태는 비선택으로 유지된다.
