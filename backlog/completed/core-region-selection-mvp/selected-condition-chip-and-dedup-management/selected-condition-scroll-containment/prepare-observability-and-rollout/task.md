## 작업 내용
- 목표: 스크롤 기능 릴리스 후 이상 징후를 빠르게 감지하고 안정적으로 롤백할 수 있도록 운영 준비를 완료한다.
- 구현 항목: 데스크톱/모바일 수동 검증 체크리스트(열기/선택/개별삭제/전체삭제/패널 접근성)를 정리한다. / 롤백 트리거(삭제 불가, 클릭 불가, 레이아웃 붕괴)와 복구 절차를 문서화한다. / `onChange` 페이로드 길이와 삭제 후 조건 수 변화 등 관측 포인트를 운영 문서에 반영한다.
- 선행조건: [T-171] 검증한다: 스크롤 도입 후 삭제/동기화 회귀와 스타일 계약 완료

## 검증과 완료 조건
- 검증 방법(테스트/리뷰/지표): 릴리스 리허설에서 체크리스트 기반 재현 가능성과 롤백 절차 실행 가능성을 확인한다.
- 산출물: 운영 체크리스트, 롤백 절차, 관측 포인트 문서
- 완료 정의(DoD): 관측/롤백/수동 검증 항목이 모두 준비되어 릴리스 승인 기준을 충족한다.
